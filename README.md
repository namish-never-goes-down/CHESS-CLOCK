# CHESS-CLOCK
I want to build a digital chess clock with multiple time modes, pause and reset functions, and an intuitive display. The clock will be designed for real chess games and will help me learn programming, electronics, and hardware design while creating a useful product for chess players.
 Features
- Blitz mode
- Rapid mode
- Custom time controls
- Pause button
- Reset button
- Dual-player timer

## Hardware
- Arduino/ESP32
- Display module
- Push buttons
- Battery power

## Status
Currently designing and testing the prototype.
